One original line roasting the gadget I use every day — my wireless earbuds — entered in make.fun's **One-Line Roast: The Gadget You Use Every Day** bounty ($5 pot, top 3 paid).

> My earbuds announce 'battery low' four times, like a soap-opera death scene, then die mid-sentence.

**99 characters** — one line, inside the 200-character limit.

## The joke

The roast is built on one concrete habit of the gadget itself: earbuds do not simply run out of power, they narrate their own ending. The little voice interrupts again and again to warn you, each announcement more dramatic than the last, and then — right in the middle of a sentence — silence. It is a soap-opera death scene performed by a pair of earbuds: all the build-up, none of the dignity, and the punchline is that the gadget dies while still talking. The detail is specific enough that anyone who wears earbuds daily has heard it; the comparison is what makes it fresh instead of another "my battery died" complaint.

## Run it

```sh
python3 main.py
```

It prints the line to stdout and writes the same line to `/output/entry.txt`, the file the make.fun judge reads. The program checks the line first: exactly one line, no edge whitespace, no double spaces, sentence punctuation at the end, the gadget named, and at most 200 characters.
